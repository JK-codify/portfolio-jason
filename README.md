# Jason Kuate — Portfolio

Next.js + Tailwind portfolio with an African-motif design system: a
talking-drum hero image, geometric-pattern section dividers, and a dark
slate + cyan/teal color scheme.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Images

Already placed in `public/images/`:
- `african-drum.jpg` — hero visual
- `african-pattern-color.jpg` — section divider strips
- `african-pattern-dark.jpg` — subtle card background texture

## Customize

Edit `components/JasonPortfolio.jsx`:
- `projects` array — project descriptions, features, tech stack
- `skillGroups` array — skill categories
- Footer links — swap in your real email, GitHub, and LinkedIn

## Deploy

Push to GitHub, then import at https://vercel.com/new for a zero-config
Next.js deploy.
